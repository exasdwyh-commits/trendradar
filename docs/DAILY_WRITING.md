# 日常创作指南

主线是「选题 → 素材 → 公众号母稿 → 多平台版本 → 导出与发布记录」。首页工作台优先帮助你接着写，选题、素材和发布各有固定入口。

## 方便启动

在 Windows 中双击项目根目录的 **`启动写作台.cmd`**，等待提示「写作台已就绪」，浏览器会自动打开工作台，默认地址是 `http://127.0.0.1:8787`。

- 电脑需安装 Python 3.11 或以上、Node.js 20 或以上。首次启动会创建项目 `.venv`，安装缺少的依赖并构建前端，因此需要联网。
- 后续启动复用环境和构建；修改前端后，下次启动会重新构建。
- 重复双击会打开已运行的写作台。端口被其他程序占用时会提示，不会关闭其他程序。
- 保持启动窗口打开，写完按 Ctrl+C 停止服务。稿件与素材保存到配置的 `DATA_DIR`，默认是项目的 `data` 目录。
- 启动只提供本地写作界面；抓取简报由你在页面里主动触发，AI 写作由编辑器里的动作触发。

需要换端口或排查时，在项目目录的 PowerShell 中运行：

```powershell
.\启动写作台.cmd --port 8788
.\启动写作台.cmd --check       # 只检查环境，不启动服务
.\启动写作台.cmd --rebuild     # 强制重新构建前端
.\启动写作台.cmd --no-browser  # 启动服务，手动打开浏览器
```

如果提示检测到旧版服务，先在原来的启动窗口按 Ctrl+C，再重新双击。详细模型配置见 [模型配置](MODEL_SETUP.md)。

## 每天怎么用

1. **打开工作台。** 有未完成稿件时，点「继续写作」。首页只推荐最近更新的灵感或草稿；待发稿单独显示，避免继续写作入口把你带回已完成的内容。
2. **需要新选题时看选题简报。** 工作台显示最近一期简报的三个候选，并标明日期。从一个切口直接开写，素材会自动绑定；完整简报中也可以收藏素材、忽略不适合的选题。
3. **随时留素材。** 首页的「记一条笔记」「收藏链接」直接打开对应表单。笔记写观点、引文或观察；链接可抓取正文。回到编辑器后，在素材面板绑定到当前母稿。
4. **完成公众号母稿。** 写下标题和核心判断，整理依据，再写正文。新建稿件默认目标平台是公众号。编辑器支持创作规划、素材、AI 助手、版本、平台版本和发布面板；正文自动保存，重要阶段可手动保存版本。
5. **写完标记待发。** 从编辑器状态菜单或稿件列表菜单标记「待发」；编辑器提示仍需核对的项目时，先完成证据、核心判断和大纲等检查。工作台随即能看到待发布的稿件，稿件列表可按灵感、草稿、待发、已发布筛选。
6. **改编与记录发布。** 在编辑器「平台版本」中生成或修改各平台版本，再导出或复制内容。去目标平台后台发布，之后在「发布」面板记录平台和链接；发布中心查看各稿件的发布情况。

演示选题、素材和生成结果保留「演示」标识。真实素材的 AI 写作需要配置模型；你也可以直接手动写作。

## 前端分工

需要连续协作时，进入编辑器右侧 **创作 Agent**：整理素材与缺口 → 确认大纲 → 连续分节起草、审稿与改编 → 查看候选并采用。可暂停后继续，原稿快照会保留。完整操作与限制见 [创作 Agent](WRITING_AGENT.md)。

| 入口 | 日常职责 |
|---|---|
| 工作台 `/` | 开始一天：续写、待发稿、最近稿件、选题候选、素材随手记 |
| 选题简报 `/brief` | 判断值得写什么：看来源、理由和切口，收藏或延伸创作 |
| 稿件 `/studio` | 管理进度：搜索、状态筛选、打开、归档 |
| 编辑器 `/studio/:id` | 完成一篇母稿，再改编平台版本、导出、记录发布 |
| 素材库 `/materials` | 集中保存与整理依据，再绑定到稿件 |
| 发布中心 `/publish` | 查看跨平台版本和发布记录 |

扩展工具与系统分组默认收起，按需展开。窄屏下主要入口横向排列，编辑器工具栏换行；桌面编辑器自动收起导航，为正文和右侧面板留空间。沿用已有浅色、深色主题和组件样式，避免每天写作时切换视觉习惯。

工作台汇总只读取数据，不下载完整正文、版本历史或 AI 历史。页面按需加载，切换页面会取消旧请求，导航数量在页面切换后更新。
