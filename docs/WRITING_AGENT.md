# 创作 Agent

打开稿件，在编辑器右侧点击 **创作 Agent**。它使用稿件已经绑定的素材、原文摘录、创作规划和你的要求，按步骤协作完成公众号母稿与平台版本。

## 日常操作

1. 在素材面板绑定依据。已有未保存的创作规划时，先保存它。
2. 在 Agent 中填写这篇想怎么写，选择需要的小红书、知乎、头条或 X 版本。点「整理素材并规划」。
3. 查看资料缺口、原文摘录和大纲。可以修改标题、读者、核心判断及每节目标；需要补资料时，去素材面板补齐后点「重新规划」。
4. 点「确认大纲并连续起草」。这会把当前创作规划更新成确认后的方向和大纲，然后依次生成各节、审阅候选母稿、准备所选平台版本。
5. 查看候选正文、审稿建议和平台版本。点「采用母稿和平台版本」才会应用到正文，原稿会先保存快照。审稿建议保留给你判断，不会自动逐条替换正文。
6. 修改、核对后，通过已有发布流程导出与记录链接。Agent 不执行发布。

模型调用仍使用 `WRITING_MODEL`，未配置时使用 `ANALYSIS_MODEL` 槽位，并遵循项目已有的预算、调用次数和重试限制。演示稿件可离线体验模板流程；演示内容不代表真实写作质量。

## 暂停、继续与失败

- 连续执行由打开的 Agent 面板驱动。关闭面板、切换到其他面板、离开稿件或点击「暂停后续步骤」，会在当前请求完成后停止后续步骤。
- 每一步完成都会写入数据库。重新打开后读回进度，点「继续执行」恢复；读进度不会触发模型调用。
- 模型失败、额度不足或格式无效时，停在当前步骤。处理原因后点「重试当前步骤」，已完成的章节和版本保留。
- 请求响应丢失时先读取进度，避免把已经完成的步骤重新提交。
- 正文、规划或素材发生变化后，旧任务停止继续应用。点「重新规划」基于最新内容开始新任务，原稿与历史任务保留。
- 多个窗口同时操作时，数据库租约与修订号阻止重复执行。进程异常结束留下的租约最多保留 15 分钟，期间界面显示当前步骤仍在执行；过期后可继续。

Agent 只整理已提供资料，列出资料缺口，不会自动检索或声称完成事实核验。大纲最多八节，单次完整输入最多 80000 字符、证据摘录合计最多 30000 字符；审稿正文最多 40000 字符，超限会提示精简而不会静默截断。

## 实现与验证

`studio/agent.py` 编排已有的规划模型、分节写作、审稿与平台改编能力。`0008_writing_agent.sql` 保存任务与当前租约。每次请求只执行一个生成步骤，不在模型请求期间持有写事务。

| API（前缀 `/api/documents/{id}/agent`） | 行为 |
|---|---|
| `GET /`（实际路径无末尾斜线） | 读取最近任务；没有任务返回 null |
| `POST /start` | 保存要求与平台选择，尚不调用模型；默认复用任务，`restart=true` 创建新任务 |
| `POST /advance` | 用 `run_id`、`revision` 执行一个步骤并保存结果 |
| `POST /confirm` | 校验作者修改后的规划，原子保存原文摘录和确认大纲 |
| `POST /adopt` | 检查输入未变化，原子保存原稿快照、母稿、章节和平台版本 |

采用失败会整笔回滚，既不留下半篇母稿，也不留下不完整的平台版本。旧任务产生的内容不能覆盖更新后的稿件。每次模型生成仍存入 AI 历史。

离线测试在 `tests/test_writing_agent.py`、`AgentPanel.test.tsx` 和 `Editor.test.tsx` 覆盖确认关卡、失败续跑、租约、输入变化、候选稿隔离、采用回滚、面板暂停与保存顺序。
