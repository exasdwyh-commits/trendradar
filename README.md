# TrendRadar 3.0 — 硬币先生 · 商业趋势与公众号创作工作台

> 每天不是告诉你“什么上热搜”，而是回答：**哪些商业变化值得长期理解，哪一件值得写。**

这个仓库已经从旧版“全网热榜雷达”彻底改造成 **商业内容专用** 工作台。旧版热搜平台、通知系统、MCP FAQ、Docker 教程、历史截图、通用关键词榜单等不再保留。

## 只做五类商业内容

1. **公司与战略**：公司动作、财报、组织变化、资本开支、产品战略。
2. **产业与利润池**：供应链、制造、能源、芯片、机器人、AI 基础设施，重点看利润迁移。
3. **商业模式**：新产品、新定价、新渠道、一人公司/小团队、AI 原生公司。
4. **AI 商业化**：不追参数榜，重点追真实 ROI、工作流替代、成本结构与企业采购。
5. **全球化与中国映射**：出海、技术授权、海外渠道、跨国供应链，以及对中国企业的映射。

纯娱乐、明星、社会猎奇、泛政治热搜、体育、短视频热榜不进入系统。

## 默认输出

后台可以抓很多，但前台每天默认只给 **3 条**，最多展开到 5 条：

- 发生了什么
- 真正改变的是什么
- 为什么是现在
- 谁受益 / 谁受损
- 商业上钱往哪里流
- 对中国企业意味着什么
- 强化或削弱哪个长期趋势
- 证据缺口
- 建议：值得写 / 继续跟踪 / 暂不下结论

## 数据纪律

来源分三层：

- **PRIMARY**：公司公告、IR/财报、监管/统计、行业组织原始数据
- **VERIFIER**：Reuters、FT 等高质量独立媒体/研究
- **DISCOVERY**：HN、Reddit、创业社区，只负责发现线索

DISCOVERY 不能单独支撑高置信结论。公司自述默认是 CLAIM，不自动当 FACT。

## 两条下游

```
高质量商业信号
      ↓
去重 / 事件簇 / 证据门禁
      ↓
┌──────────────────┬──────────────────┐
│ 认知线            │ 内容线           │
│ 值不值得长期理解  │ 值不值得今天写   │
│ → 趋势与反证      │ → TOP3           │
│ → 世界模型更新    │ → Research       │
│                   │ → Thesis Gate    │
│                   │ → Draft          │
│                   │ → Challenger     │
└──────────────────┴──────────────────┘
```

“值得写”和“值得理解”不是一个分数。

## 本地启动

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"

trendradar init
trendradar daily
trendradar serve
```

然后打开：`http://127.0.0.1:8787`

## 模型槽位

复制 `.env.example` 并配置任意 OpenAI-compatible 网关。

- `FAST_MODEL`：摘要/结构化/候选
- `COGNITION_MODEL`：趋势、双面分析、商业机制
- `RESEARCH_MODEL`：研究包
- `WRITING_MODEL`：成稿
- `CRITIC_MODEL`：挑战者，建议与 Writer 异构

没有模型时仍可采集、去重、评分、展示；**不会伪造 AI 认知结果**。

## 公众号工作流

```
候选 → Research → 核心观点确认 → 标题 → 结构 → 正文 → Challenger → 人工终审
```

未经观点确认，系统不允许进入正式成稿。
